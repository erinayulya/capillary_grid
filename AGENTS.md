# Версии проекта capillary_grid

- `2025b/` — основная рабочая версия пользователя; `2023a/` — её копия для MATLAB R2023a.
- При задачах с кодом проекта применять `skills/capillary-release-sync/SKILL.md`.
- Каждую согласованную правку рабочей версии `2025b/` дублировать в соответствующем файле `2023a/`, адаптируя её к R2023a. Это правило также действует, когда пользователь просит синхронизировать свои ручные изменения.
- Сохранять специальные изменения совместимости в `2023a/`; не заменять эту папку целиком при обычной синхронизации.
- Правила в `2025b/AGENTS.md` и `2023a/AGENTS.md` сохраняют ограничения на расчётную часть и необходимость согласования. Дублирование не разрешает дополнительные изменения расчёта.
- Не считать проверки в R2025b подтверждением запуска в R2023a. Указывать фактическую версию проверки.
