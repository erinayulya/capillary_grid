ГЕНЕРАТОР ЛОГНОРМАЛЬНЫХ СЕТОК
Дата: 03.11.2026

ЗАПУСК
Перейдите в папку generate_lognorm_mesh в MATLAB и вызовите:
    run(50,50)
или
    folder = run(50,50);
Первый аргумент — число строк n, второй — число столбцов m.
Числа должны быть целыми и положительными. Ограничения формата Excel:
n <= 1048575, m <= 16383; фактический размер ограничен также памятью и диском.

Папка генератора — самостоятельная, рядом с 2025b и 2023a.
Функция run(n,m) отличается от run без аргументов в расчётной программе.
Не подключайте обе папки рекурсивным genpath. Запускайте генератор из его
папки; перед запуском расчёта перейдите в 2025b либо 2023a.
Результаты всегда записываются рядом с файлом генератора, независимо от pwd.

ПАРАМЕТРЫ
Mu и sigma — среднее и стандартное отклонение натурального логарифма
ИСХОДНОЙ площади A в м². Это не параметры диаметров и не среднее самой A.
В run.m задана согласованная таблица (пять mu для каждой sigma):
sigma=0.1: -18.36 -17.36 -16.36 -15.36 -14.36
sigma=0.2: -18.06 -17.21 -16.36 -15.51 -14.66
sigma=0.3: -17.76 -17.06 -16.36 -15.66 -14.96
sigma=0.4: -17.46 -16.91 -16.36 -15.81 -15.26
sigma=0.5: -17.16 -16.76 -16.36 -15.96 -15.56
Всего 25 сочетаний, по одной независимой случайной сетке для каждого.
У run только два входа. Для изменения таблицы редактируют блок sigmaValues
и muValues в run.m; проверяется правило mu +/- 3*sigma и уникальность имён.
В именах sigma записывается с одним, mu с двумя знаками после точки.

РАСПРЕДЕЛЕНИЕ И ГРАНИЦЫ
A = exp(mu + sigma*Z), Z — независимое стандартное нормальное число.
Диаметр d = 2*sqrt(A/pi) ограничен 0.1–1 мм включительно.
Площади ограничены pi*(0.1e-3/2)^2 .. pi*(1e-3/2)^2 м².
Неподходящие площади выбираются заново; значения не обрезаются к границам
и не умножаются на общий масштаб. Получается усечённое логнормальное
распределение. Mu +/- 3*sigma укладывается в допустимый ln(A), поэтому
вероятность подходящего исходного значения не менее 99.73%.
После усечения и для конечной случайной сетки выборочные среднее/разброс
ln(A) могут отличаться от mu/sigma. Маленькая сетка не обязана повторять
гладкую теоретическую кривую.

ДОЛИ И ПЛОЩАДИ
Физические площади в Excel остаются в м²; их сумма не приводится к 1.
Доля площади одного капилляра равна A_i / sum(A всех H и V).
Сумма таких долей равна 1 с погрешностью округления; контроль записан в MAT.
В PDF показана теоретическая плотность усечённого распределения:
f_tr(A) = f_LN(A)/(F_LN(Amax)-F_LN(Amin)) внутри диапазона, 0 вне его.
Её интеграл равен 1, то есть 100%. Высота плотности не является процентом.

РЕЗУЛЬТАТЫ
generate_lognorm_mesh/
  run.m
  results/
    50_50/
      manifest.mat
      distribution_visualization.pdf
      sigma_0.1_mu_-18.36/
        horizontal_areas.xlsx
        vertical_areas.xlsx
      ... ещё 24 папки sigma_<sigma>_mu_<mu>/

horizontal_areas.xlsx: n строк, m+1 столбцов, площади горизонтальных капилляров.
vertical_areas.xlsx: n+1 строк, m столбцов, площади вертикальных капилляров.
Первый лист, только числа в м², без заголовков и дополнительных листов.
Для загрузки в расчётный run выберите соответствующие горизонтальную
и вертикальную таблицы из ОДНОЙ папки sigma_..._mu_....

distribution_visualization.pdf: один PDF из пяти векторных страниц.
На каждой странице фиксирован sigma и пять кривых mu из его строки таблицы.
Оси линейные и начинаются с нуля, как на последних графиках в чате.
Единица горизонтальной оси — 10^-7 м²; плотность дана на эту единицу.
По вертикали каждая страница имеет собственный масштаб, чтобы видеть пики.
Кривые показывают теоретическое распределение, а не гистограммы выборок.
Рисунки формируются в невидимом окне; окна расчётной программы не меняются.

manifest.mat содержит структуру generation: размеры, единицы, границы,
таблицы параметров, состояние rng перед генерацией, дату и сводку 25 сеток.
В сводке — sigma/mu, имя папки, минимум/максимум диаметра и сумма долей.

ПОВТОРНЫЙ ЗАПУСК И ОШИБКИ
Существующая results/n_m не перезаписывается: ResultsExist до генерации.
Для другой случайной реализации того же размера сначала переместите
предыдущую папку n_m. Два одновременных запуска одного размера не рассчитаны
на совместную работу.
Все файлы сначала создаются во временной дочерней папке внутри results,
которая переименовывается в n_m после полного успешного завершения.
При ошибке записи или экспорта временные результаты удаляются; ранее
сохранённые наборы не затрагиваются.
При неверных размерах — ошибка validateattributes/narginchk;
Parameters/ThreeSigmaRange/DuplicateNames — неверная таблица параметров;
CreateFolder/PublishFailed — ошибка файловой системы;
SamplingFailed — превышен предел повторной выборки;
ошибки writematrix/exportgraphics передаются вызывающему коду.

СЛУЧАЙНОСТЬ И СОВМЕСТИМОСТЬ
run не вызывает rng('shuffle') и не сбрасывает rng. Для воспроизводимости:
    rng(42);
    run(50,50);
Повторный запуск без явного сброса rng даёт новую случайную выборку.
Не нужны Statistics and Machine Learning Toolbox, Simulink или Excel.
Используются базовые функции MATLAB, доступные в R2023a; одна общая версия
генератора обслуживает обе версии расчётного проекта, копий внутри них нет.
Проверено 03.11.2026 в MATLAB R2025b: сетки 40x50 и 1x1, 25 комбинаций,
импорт файлов через mesh обеих версий, границы, доли и соответствие CDF,
защита повторного запуска, очистка после ошибки записи, PDF из пяти страниц.
Совместимость параметров exportgraphics и writematrix сверена по официальной
документации R2023a. MATLAB R2023a не установлен; запуск в нём не проверялся.
Код main.m, run.m, model/, solver/ и структура Net расчётного проекта
генератором не изменяются.
