run.m: run()
  Создаёт окно параметров; результат возвращаемым аргументом не выдаёт.
  При открытии пропорционально уменьшает элементы и шрифты под монитор
  с указателем мыши, центрирует окно и оставляет запас для рамки и панели задач.
  Масштаб не превышает 90% исходной компоновки 700x850.
  При открытии вызывает resetSimulationWorkspace(true): очищает base workspace
  и прежние окна. Через assignin передаёт свежий Net под именем runParameters,
  запускает main через evalin. Окно параметров закрывается очисткой main;
  завершающий delete выполняется только для ещё действительного fig.
  Требует графической среды MATLAB.
  changeAreaType(~,~): переключает панели способов задания площадей.
  Доступны «Матрица площадей» (начальный выбор) и «Случайная».
  [Ah,Av,ok] = getGeometry(): читает геометрию из элементов интерфейса,
    проверяет допустимость значений и согласованность размеров матриц.
  previewNetwork(~,~): проверяет размеры и вызывает plotNetwork.
  startMain(saveResults): проверяет параметры, собирает Net, передаёт
  одноразовый переключатель runRecordResults и запускает main.
  «Запустить по шагам» передаёт false; «Запустить и сохранить результаты» - true.
  main сохраняет переданный Net и дополняет параметры и начальные состояния.

solver/solvePressureFlow.m: Net = solvePressureFlow(Net)
  Вход: геометрия, физические параметры, граничные условия и поля состояний.
  При наличии P и Q подходящих размеров использует их как начальное приближение.
  Решает совместную нелинейную систему давлений и расходов методом Ньютона
  с масштабированием и уменьшением шага.
  Выход: Net с P, H.Q, V.Q, NewtonIterations и согласованными H/V.Move/Regime.
  Один вызов решает сеть с остановкой/открытием по текущему пробному P.
  Вызывает pressureFlowScaling, calcResidualJacobian и storeSolvedBranches.
  storeSolvedBranches(Net): записывает ветви принятого решения через
  capillaryEquation; P/Q/Sat/State/Dir не меняет, второй системы не решает.
  Для закрытой вертикальной границы с мениском задаёт Move=2, Regime=0.
  Некорректный шаг/неудачный поиск шага: error; превышение допуска после
  итераций: error solvePressureFlow:NoConvergence, результат не возвращается.

solver/calcResidualJacobian.m:
  [F,J] = calcResidualJacobian(Net,X,idxP,idxQH,idxQV)
  Собирает балансы расходов в узлах и уравнения всех капилляров.
  X содержит давления, затем горизонтальные и вертикальные расходы.
  Выход: F — столбец невязок; J — разреженный якобиан.
  Вызывает capillaryEquation; для закрытых вертикальных границ задаёт Q=0.
  Net не изменяет. Все активные компоненты F имеют единицы м3/с.

solver/pressureFlowScaling.m:
  [xScale,fScale] = pressureFlowScaling(Net,idxP,idxQH,idxQV)
  Возвращает масштабы неизвестных и уравнений: 1e3 Па и 1e-11 м3/с.
  Все fScale=1e-11 м3/с, независимо от смены ветви во время итераций.
  Давления в X масштабируются 1e3 Па, расходы — 1e-11 м3/с.
  Net не изменяет.

model/capillaryEquation.m:
  [f,dfdp,dfdq,regime,move] = capillaryEquation(Net,dp,q,A,S,state,regime,move)
  Уравнение одного капилляра: f=q-Q(dp), м3/с, и производные
  dfdp [м3/(с*Па)], dfdq=1. Все аргументы капилляра скалярные.
  Для одной фазы — Пуазейль; для Move=2 — q=0 независимо от dp.
  При входном Move=1 или 3 ветвь определяется текущим dp:
  dpStar=max(dp-Pc,0); при нуле Move=3, Regime=0, q=0.
  Иначе Move=1; при Aeff>0 плато до sqrt(B^3/Aeff) включительно,
  вязкая ветвь выше; это единая граница Pi=PiCrit. При Aeff<=0 только плато.
  Плато: Q=A*(dpStar/B)^3; вязкая ветвь: Q=A*dpStar/Aeff.
  Входной regime сохранён для совместимости, не фиксирует ветвь.
  Для мениска вызывающая функция ориентирует dp и q с помощью Dir.
  Net не изменяет. Дополнительные выходы сообщают использованную ветвь.
  case 2 и realCubeRoot закомментированы, не удалены и не выполняются.

model/calcCanMove.m: Net = calcCanMove(Net)
  Читает State, прежний Move, Dir, Sat, P, геометрию и параметры Pc.
  Вызывает calcWaterConnectivity. Обновляет H.Move и V.Move.
  Move=2 сохраняется для существующего мениска; Move=3 проверяется повторно.
  Для перехода к Move=1 нужны разрешённая связность/граничный случай и dP>Pc.
  Это предварительный выбор по прежнему P; solvePressureFlow уточняет 1/3
  по своему решению. Связность и необратимость Move=2 не изменены.

model/calcWaterConnectivity.m:
  [WaterConnectedH,WaterConnectedV] = calcWaterConnectivity(Net)
  Обход в ширину по капиллярам с Sat==0 от правой границы и, при
  VerticalBC=true, нижней. Возвращает логические матрицы размеров H.A и V.A.
  Закрытые верхние/нижние граничные капилляры исключаются из передачи метки.
  Net не изменяет.

model/calcRegime.m: Net = calcRegime(Net)
  По ориентированному перепаду давления, насыщенности и параметрам модели
  выбирает H.Regime/V.Regime только для State=1 и Move=1.
  Остальные значения Regime сбрасывает в 0. Вызывает capillaryEquation
  для единого правила двух режимов. Старый calcOneRegime закомментирован.
  Окончательный Regime записывает solvePressureFlow по принятому давлению.

model/calcTimeStep.m: Net = calcTimeStep(Net)
  Вычисляет Net.dt как минимальное время до заполнения подвижного капилляра.
  calcTimeStepEval(Cap,Net): минимизирует (1-S)*L/(abs(Q)/A)
  среди State=1, Move=1, S<1-1e-12; при отсутствии кандидата возвращает Inf.
  Предупреждение при Inf выдаётся, если вообще нет Move=1.

model/calcSaturation.m: Net = calcSaturation(Net)
  Обновляет H.Sat/V.Sat по прежним Q и Net.dt.
  calcSaturationEval(Net,dt,L): здесь Net означает только ветвь H либо V;
  для State=1, Move=1 вычисляет min(1,Sat+abs(Q)/A*dt/L).

model/calcState.m: Net = calcState(Net)
  Для State=1 и Sat>=1-1e-12 устанавливает State=2, Sat=1,
  Move=Dir=Regime=0. После завершения всех переходов строит маску внутренних
  узлов с нефтью: State=2 с обоих концов; State=1 только у входа по Dir,
  включая Sat=0. Нефть у противоположного конца не считается достигшей узла.
  processNode(Net,row,col): на каждом вызове проверяет всех водяных соседей
  узла с нефтью. При State=0 и расходе от узла задаёт State=1, Sat=0, Move=3,
  Dir=+1/-1, Regime=0. При Q=0 или расходе к узлу мениск не создаётся.
  Проверка не ограничена узлами, достигнутыми именно на текущем шаге:
  смена знака Q позже также может создать мениск. P/Q не изменяются.
  Обход линейный по размеру сети; используются последние рассчитанные Q.

visualization/drawNetwork.m: drawNetwork(Net,move,targetAxes)
  Рисует состояние сети в новом окне figure при каждом вызове.
  При переданном targetAxes рисует в этих осях без создания нового окна.
  При Net.VerticalBC=false верхние и нижние вертикальные капилляры рисует
  серыми без маркеров Move.
  move необязателен (false): при true показывает маркеры Move: 0 —
  светло-серый, 1 — зелёный, 2 — красный, 3 — жёлтый.
  Использует геометрию, State, Sat, Dir, Move; при наличии H.Sat_prev
  читает согласованный комплект H/V.Sat_prev, State_prev, Dir_prev.
  Net не изменяет; возвращаемого значения нет. Маркеры берёт непосредственно
  из Net.H.Move/Net.V.Move, без вызова calcCanMove.
  Выводит легенду: при move=true четыре кода Move, отдельно положение
  мениска на линии капилляра и, при наличии *_prev, его прежнее положение.
  Для временного удержания указано Pc >= dP: равенство тоже запрещает движение.
  Легенда используется и при скрытой отрисовке для PDF.
  drawMoveMarker(targetAxes,x,y,moveState): рисует маркер состояния движения.

visualization/plotNetwork.m: plotNetwork(N_cols,N_rows)
  Рисует схему сети по числу внутренних столбцов и рядов.
  Проверяет положительные целые скалярные размеры; создаёт отдельное окно.
  Не рассчитывает давления и фазы, не получает и не изменяет Net.

setupProject.m: setupProject()
  Подключает корень, model, solver, visualization, reporting по расположению файла.
  Вызывается main и run.
  Не вызывает savepath.

reporting/resetSimulationWorkspace.m:
  resetSimulationWorkspace(openingInterface)
  Служебная очистка перед новым запуском. openingInterface — scalar logical,
  по умолчанию false. Удаляет все figure/uifigure через findall/delete,
  сбрасывает persistent-сессию simulationReport через clear функции.
  true (run): clearvars в base workspace до создания окна параметров.
  false (main): clearvars в workspace вызывающего скрипта с сохранением только
  runParameters/runRecordResults; свежие runParameters присваиваются Net,
  затем одноразовая переменная удаляется. Старые поля Net не переносятся.
  Нет возвращаемых значений. Файлы results и MATLAB path не изменяются.
  Нет вызовов модели/решателя; цикл и порядок расчёта остаются в main.

reporting/simulationReport.m:
  [output,restoredNet] = simulationReport(action,Net,options,outputRoot,maxSteps)
  Одна persistent-сессия записи; start сбрасывает прежнюю. Входной Net не изменяется;
  функции модели/решателя не вызываются, шаги/основной цикл здесь не выполняются.
  start: сохраняет parameters=Net, создаёт папку запуска при recordResults=true,
  с именем run_YYYYMMDD_HHMMSS; при занятом имени добавляет _2, _3 и т.д.
  запускает таймер. options для start — recordResults=false (logical);
  outputRoot=results/ проекта, maxSteps=10000 (положительное целое число).
  capture: фиксирует reportNet после calcRegime перед solvePressureFlow.
  В пошаговом режиме сразу рисует этот снимок с Move; при записи сохраняет
  его в памяти до успешного завершения шага. На время capture таймер остановлен.
  snapshot: после calcTimeStep суммирует два интервала времени шага, обновляет
  счётчики, запоминает lastNet и пишет снимок отчёта как Net, итог решения
  как solvedNet в MAT. Поля Net модели и основной порядок не изменяет.
  Повторно график не рисует; снимок 0 (без capture) рисуется после первого решения.
  В режиме записи также обновляет summary.mat с итоговым Net.
  next: возвращает 'Продолжить'/'Стоп', показывает прежний диалог в пошаговом
  режиме; в режиме записи отвечает автоматически (стоп при плохом dt/лимите).
  При продолжении запоминает dtUsed=Net.dt и запускает таймер до возврата в main.
  finish: уточняет причину остановки, записывает итог, собирает PDF, возвращает
  result, выводит причину остановки и освобождает сессию.
  fail: options — исходный MException. При активном таймере учитывает время
  неудачного вычисления; возвращает result и lastNet (до снимка 0 — parameters).
  В режиме записи сохраняет причину ошибки и частичный PDF по завершённым
  снимкам, включая титульный PDF, если снимков нет. При ошибке записи отчёта
  предупреждает simulationReport:PartialReportFailed; main повторно выбрасывает
  исходную ошибку расчёта. Неудачный шаг не увеличивает steps/totalTime.
  Во всех остальных действиях restoredNet равен входному Net.
  Вызывает measureComputeTime, saveSimulationStep,
  writeSimulationReport и drawNetwork. Без start: simulationReport:NotStarted;
  неверное действие: simulationReport:UnknownAction.
  saveSummary(session,Net): пишет result, parameters и последний принятый Net.
  До finish/fail статус в checkpoint-summary — 'Расчёт не завершён.'.
  При принудительном прерывании без catch итоговый PDF может отсутствовать.

reporting/measureComputeTime.m:
  [result,timer,stepComputeTime] = measureComputeTime(action,result,timer)
  Только хронометраж; не принимает Net и не вызывает расчётные функции.
  action='start': запускает tic, возвращает идентификатор timer; третий вход
  необязателен. action='stop': измеряет секунды toc(timer), прибавляет их
  к result.totalComputeTime, возвращает stepComputeTime и пустой timer.
  action='fail': дополнительно записывает интервал в result.failedComputeTime.
  result — скалярная структура; timer — скалярный идентификатор tic либо [].
  stepComputeTime — скаляр double в секундах; при start равен 0.
  stop/fail без timer: ошибка measureComputeTime:NotStarted;
  неизвестное action: ошибка measureComputeTime:UnknownAction.
  Замер начинается/заканчивается в simulationReport по вызовам из main; не включает
  запись MAT, построение PDF, графики, диалоги и инициализацию main.

reporting/saveSimulationStep.m:
  saveSimulationStep(solvedNet,result,dtUsed,stepComputeTime,reportNet)
  Добавляет вне Net метаданные flowLaw='twoRegimeCurrentPressure', чтобы
  валидатор отличал новые уравнения от архивного выбора по прежнему давлению.
  Записывает step_XXXXXX.mat по result.directory/result.steps.
  reportNet — необязательная копия для отчёта; по умолчанию равна solvedNet.
  В MAT Net=reportNet — состояние рисунка и таблиц; solvedNet — результат решения.
  reportPhase='beforeSolve' при переданной копии шага >0, иначе 'afterSolve'.
  Сохраняет Net, solvedNet, reportPhase, step, dtUsed, elapsedTime=result.totalTime,
  stepComputeTime и totalComputeTime=result.totalComputeTime.
  Все времена — скалярные секунды; step — скалярный номер снимка от 0.
  Net и result не изменяет, возвращаемого значения нет, расчёт не запускает.

reporting/writeSimulationReport.m: pdfPath = writeSimulationReport(directory)
  Читает summary.mat и step_*.mat из папки запуска, создаёт report.pdf.
  Первый лист содержит параметры и итог, затем шаг 0 и по листу на шаг:
  выполненный dt, накопленное модельное время, следующий solvedNet.dt, рисунок и 16 матриц.
  На первом листе также выводит постоянные по симуляции матрицы капиллярного
  давления p_c для H и V, Па. Таблица Net.P занимает ширину колонки H
  с теми же отступами и шириной width/2-60, что H.Q;
  рисунок и узкая легенда справа от него — единым блоком над колонкой V.
  Легенда: одна колонка, шрифт 7 pt, длинные подписи разбиты на строки.
  Рисунок и все матрицы берутся из Net после loadSimulationStep: состояние перед решением,
  P/Q предыдущего шага и обновлённые Sat/State/Move/Regime. Отдельного
  расчёта Move нет. Под основными полями выводит сохранённые Move, как
  на рисунке, затем Δp−p_c по давлению того же Net только для State=1.
  Старые MAT читаются через loadSimulationStep с сохранением прежнего вида PDF;
  фаза снимка подписана. Следующий dt берётся из snapshot.solvedNet.
  На первом листе — общее время вычислений, включая шаг 0; при ошибке отдельно
  указано время незавершённого вычисления. На листе шага — время его вычислений
  и накопленное время вычислений (секунды). Старые MAT без замеров поддерживаются:
  вместо чисел выводится «не измерялось».
  Размер листов увеличивается под размер матриц с сохранением книжных пропорций.
  exportPage(fig,pdfPath,width,height,append): фиксирует размер в пунктах PDF
  (0.75*width+3.5, 0.75*height+3.5); для 3x3 узлов — 806x1106 pt.
  width/height — скалярные размеры макета в пикселях; append — logical.
  Скрытое окно создаётся с WindowStyle=normal, Resize=off; перед экспортом
  восстанавливается его размер. exportgraphics получает Width/Height/Units,
  Padding=0 и PreserveAspectRatio=off (проверено в MATLAB R2025b).
  Легенда имеет отдельное место справа от рисунка; пределы осей сети
  задаются по геометрии с полями 0.3, без растянутой пустой области.
  Числа печатаются с 6 значащими цифрами. MAT хранит полную точность.
  Верхняя строка и левый столбец индексов имеют одинаковую цветную заливку.
  Использует скрытое окно, закрываемое через onCleanup, и exportgraphics MATLAB.
  Можно повторно собрать PDF из сохранённых MAT без повторного расчёта.

tests/runTests.m — скрипт, запускаемый из папки tests.
  resultsTarget по умолчанию указывает на results текущего проекта.
  Вызывает checkResults; сохраняет сводку в testSummary и выводит её таблицей.
  Для одного запуска можно изменить resultsTarget либо вызвать checkResults напрямую.

tests/checkResults.m: reports = checkResults(target, options)
  Вход target: папка results или одна папка запуска; по умолчанию results проекта.
  options: необязательная структура допусков flow, pressure, saturation, time,
  relative. Значения и единицы описаны в variables.txt и start.txt.
  Читает parameters.mat, численно упорядоченные step_*.mat и summary.mat.
  Проверяет диапазон P, баланс узлов, State/Sat/Move/Dir/Regime/Q, закрытые
  границы, капиллярный порог, следующий dt, историю *_prev и переходы между
  соседними шагами, источник новых менисков и причину завершения без прорыва.
  Продвижение и распространение восстанавливает независимо по прежним Q/dt
  и графу узлов, не вызывая calcState/calcSaturation/calcCanMove.
  Для старых MAT без flowLaw выбор Move сравнивает с прежним P;
  их уравнения и выбор ветви Regime по Pi не проверяет.
  Для flowLaw=twoRegimeCurrentPressure независимо проверяет расход мениска,
  Move и Regime по решённому P (checkCurrentLaw), включая начальный шаг.
  На начальном шаге новой схемы Move/Regime могут отличаться от parameters;
  State/Sat/Dir должны совпадать. Новые поля в Net не добавлены.
  isCurrentLaw(sample) определяет правила по метаданным MAT, не по bound.
  Выход reports: массив структур directory, report, steps, errors, warnings,
  allCorrect. steps здесь — число проверенных снимков, включая шаг 0.
  Побочный эффект: создаёт/перезаписывает UTF-8 tests_relults.txt в каждой папке.
  Net, исходные MAT и PDF не изменяет. Состояние расчёта не пересчитывает.
  ERROR означает нарушение данных/баланса/состояния/переходов либо неполную
  проверку. WARNING — дополнительное требование к диапазону P
  или Regime=0 у неподвижного мениска.
  Любой ERROR/WARNING исключает итог all correct. Сообщение включает путь MAT,
  номер правила, индекс узла/капилляра, значения и описание несоответствия.
  Ошибки чтения отдельного шага регистрирует и продолжает со следующим;
  отсутствие целевой папки/запусков либо невозможность записи отчёта — error.
  Локальные функции:
    checkRun: проверка одной папки и запись отчёта; вложенные issue/edges
      формируют сообщения, checkSnapshot/checkInitial/checkTransition/checkEnding
      проверяют снимок, исходное состояние, переход и завершение соответственно;
      compareConstants проверяет постоянство параметров и геометрии.
    requireSample/requireNet: обязательные поля, типы, размеры и допустимые коды.
    capillaries: временная объединённая таблица H(:)/V(:), перепады и топология.
    edgeName: ориентация и индексы капилляра для отчёта.
    waterPath: независимый обход Sat==0 от правой/открытой нижней границы,
      затем проверка выхода воды с учётом специальных случаев calcCanMove.
    nextTime: ожидаемое время следующего заполнения; sameTime: сравнение времени.
