1. РАЗМЕРЫ И ИНДЕКСЫ

H — горизонтальные, V — вертикальные капилляры.
При nRows рядах и nCols столбцах внутренних узлов:
  H.A и все поэлементные поля H: nRows x (nCols+1).
  V.A и все поэлементные поля V: (nRows+1) x nCols.
  P: nRows x nCols.
Обязательны V.Ny=H.Ny+1 и H.Nx=V.Nx+1.
i — индекс строки сверху вниз; j — индекс столбца слева направо.
В формулах узлов индексы H, V и P смещены: обращаться к реализации
calcResidualJacobian/processNode, а не считать их одинаковыми координатами.

2. ПОЛЯ Net

Net.mu1: динамическая вязкость первой фазы (воды), Па*с.
Net.mu2: динамическая вязкость второй фазы (нефти), Па*с.
Net.L: длина капилляра, м.
Net.sigma: поверхностное натяжение, Н/м.
Net.theta: угол смачивания, рад.
Net.kdyn: безразмерный коэффициент динамической модели, в main равен 2.
Net.bound: безразмерный множитель границ выбора режима, в main равен 2.
Net.VerticalBC: логический флаг; true — открыты верх и низ,
  false — расходы через верхние/нижние граничные капилляры равны нулю.
  При false drawNetwork отображает эти капилляры серыми без маркеров Move.
Net.H.P0: заданное давление слева, Па.
Net.V.P0: заданное давление сверху, Па, используется при открытых границах.
  Справа и снизу давление 0 Па задано непосредственно в функциях.
Net.P: давления внутренних узлов, Па; создаёт solvePressureFlow.
Net.dt: время очередного шага, с; создаёт calcTimeStep; возможно Inf.
Net.NewtonIterations: значение счётчика iter последнего решения Ньютона.
  Не является самостоятельным признаком достижения точности.

Далее Cap означает Net.H или Net.V:
Cap.A: площади поперечного сечения, м2; задаются main либо интерфейсом.
Cap.Nx, Cap.Ny: число столбцов и строк матрицы A, определяются в main.
Cap.Q: объёмные расходы, м3/с; результат solvePressureFlow.
  Положительный H.Q направлен вправо, положительный V.Q — вниз.
Cap.Sat: доля второй фазы (нефти), безразмерная, от 0 до 1.
  0 — вода; 1 — нефть. Обновляют calcSaturation и calcState.
Cap.State: код заполнения:
  0 — первая фаза; 1 — капилляр с мениском; 2 — вторая фаза.
  State=1 допускает Sat=0 для только что созданного мениска.
Cap.Move: код подвижности:
  0 — нет мениска; 1 — движение разрешено;
  2 — защемление (сохраняется при последующих calcCanMove);
  3 — временное удержание, возможна повторная активация.
  Обновляют main, calcState и calcCanMove.
Cap.Dir: ориентация мениска:
  +1 — вправо для H / вниз для V; -1 — влево для H / вверх для V;
  0 — нет ориентированного мениска. Это не текущий знак расхода Q.
  Задаётся при создании мениска, сбрасывается при полном заполнении.
Cap.Regime: ветвь уравнения подвижного мениска:
  1 — капиллярное плато; 2 — полная модель; 3 — вязкое приближение.
  0 задаётся при инициализации/сбросе; для State~=1 уравнение Пуазейля
  выбирается по State независимо от Regime. У нового Move=3 тоже Regime=0.
Cap.Sat_prev, Cap.State_prev, Cap.Dir_prev: копии перед текущим шагом
  для drawNetwork; заполняются в main и не участвуют в решении системы.

3. ЛОКАЛЬНЫЕ ПЕРЕМЕННЫЕ РЕШАТЕЛЯ

nP, nQH, nQV: числа давлений и расходов H/V; n — их сумма.
idxP, idxQH, idxQV: матрицы индексов соответствующих неизвестных в X.
X: общий столбец [P(:); QH(:); QV(:)] со смешанными единицами.
F: вектор невязок; баланс узла — м3/с; уравнение капилляра — Па либо м3/с.
J: разреженный якобиан dF/dX; единицы зависят от строки и столбца.
rowIdx, colIdx, jacVal: тройки для сборки J через sparse.
xScale, fScale: масштабы X и F; pScale=1e3 Па, qScale=1e-11 м3/с.
Dx, DfInv: диагональные матрицы xScale и 1./fScale.
dz: безразмерная поправка; dx=xScale.*dz — поправка в физических единицах.
alpha в solvePressureFlow: множитель уменьшения шага Ньютона.
Xtrial, Ftrial: пробное решение и его невязка.
err: norm(F./fScale,inf); tol=1e-8 — допуск; maxIter=50 — лимит.

4. ЛОКАЛЬНЫЕ ПЕРЕМЕННЫЕ ФИЗИЧЕСКОЙ МОДЕЛИ

A: площадь одного капилляра, м2; r=sqrt(A/pi) — радиус, м.
S или Sat: доля нефти; l2=S*L, l1=L-l2 — длины нефти и воды, м.
q: расход, м3/с; v=q/A — скорость, м/с.
  В расчёте насыщенности/шага используется скорость abs(Q)/A.
dp, dP: перепад давления, Па; для мениска учитывается ориентация Dir.
Pc: 2*sigma*cos(theta)/r — капиллярное давление, Па.
dpStar: dp-Pc, Па.
muSm или mu_sm: выбранная вязкость смачивающей фазы, Па*с;
  mu1 при theta<pi/2, иначе mu2.
k: локальное имя Net.kdyn.
R: 8*pi*mu*L/A^2 — гидравлическое сопротивление, Па*с/м3.
Aeff: коэффициент перед v в уравнении давления, Па*с/м.
  Это не площадь сечения.
B: коэффициент перед вещественным v^(1/3), Па/(м/с)^(1/3).
f, dfdp, dfdq: невязка капилляра и её производные; единицы f
  определяются выбранной ветвью уравнения.
v13: вещественный кубический корень v.
vreg: скорость для регуляризации производной возле нуля (порог 1e-14).
alpha в calcOneRegime: r*Aeff/(2*mu_sm), безразмерный параметр модели;
  не связан с alpha шага Ньютона.
beta: k*sin(theta); Pi: r*dpStar/(2*sigma);
PiCrit: sqrt(beta^3/alpha); все три безразмерны.
t, tmin, tminH, tminV: времена до заполнения и их минимумы, с.
tol в calcState: 1e-12 — допуск насыщенности, не допуск Ньютона.

5. СВЯЗНОСТЬ, СОСТОЯНИЕ И ИНТЕРФЕЙС

WaterConnectedH/V: логические маски водных капилляров, связанных с выходом.
queueType, queueI, queueJ: очередь обхода; type=1 для H, type=2 для V.
head, tail: начало и конец очереди; maxElements — её ёмкость.
oldMoveH/V: прежние Move для сохранения защемления.
row, col, nodeRow, nodeCol: индексы узла при передаче мениска.
from: сторона прихода L/R/U/D, используемая processNode.
Ah, Av: матрицы площадей из getGeometry, м2; ok — успешность проверки.
N_rows, N_cols: число рядов/столбцов внутренних узлов в интерфейсе.
muRatio: элемент ввода отношения mu2/mu1 (само число находится в .Value).
AreaType: два варианта - «Матрица площадей» (по умолчанию) и «Случайная».
Random*, H_A, V_A: элементы ввода геометрии; fig — окно интерфейса.
monitors, pointer, screen: размеры мониторов, положение указателя и выбранный
  монитор в пикселях. windowScale: масштаб исходной компоновки 700x850,
  не больше 0.9; windowSize: итоговые размеры содержимого окна в пикселях.
move в drawNetwork: логический флаг отображения маркеров;
  не является матрицей Cap.Move. При true для каждого капилляра рисуется
  маркер кода Cap.Move: 0 — светло-серый, 1 — зелёный, 2 — красный,
  3 — жёлтый.
  Легенда справа различает эти маркеры и кружки текущего/прежнего положения
  мениска на линии капилляра. Временное удержание включает равенство Pc=dP.
x, y, x1, x2, y1, y2, xm, ym: условные координаты отрисовки сети;
  их нельзя интерпретировать как физические метры без масштабирования.

6. РЕЖИМ РАСЧЁТА И РЕЗУЛЬТАТЫ

recordResults: скаляр logical в main и simulationReport; false — диалоги/графики,
  true — автоматическое продолжение и запись MAT/PDF. В main копируется из
  runRecordResults до удаления одноразового флага, по умолчанию false.
runParameters: одноразовая структура свежих входных параметров из окна run;
  поля соответствуют сформированному интерфейсом Net. resetSimulationWorkspace
  передаёт её в Net в main и удаляет. Прежний Net очищается целиком.
runRecordResults: одноразовый флаг из run (или для прямого автоматического запуска);
  resetSimulationWorkspace сохраняет его при очистке main,
  копирует в recordResults и удаляет до simulationReport('start',...) и решения.
saveResults: logical-аргумент startMain в run.
simulationResult: итоговая структура действия finish или fail в simulationReport.
result: структура внутри persistent session функции simulationReport и summary.mat.
result.startedAt: локальная дата и время запуска.
result.totalTime: сумма интервалов завершённых шагов, секунды модельного времени.
result.steps: число завершённых шагов (без снимка 0).
result.status: причина остановки/текст ошибки; до finish/fail — 'Расчёт не завершён.'.
result.directory, result.pdf: пути папки запуска и итогового PDF.
parameters: копия Net перед первым решением.
reportNet: отдельная переменная step_*.mat и поле session, не поле Net.
  На шагах >0 — копия после calcRegime перед solvePressureFlow: P/Q ещё
  предыдущие, Sat/State/Move/Regime обновлены. Используется рисунком и PDF.
  Итоговый Net в MAT по-прежнему хранится после solvePressureFlow/calcTimeStep.
  На шаге 0 reportNet=Net после первого решения; старые MAT могут не иметь reportNet.
session.partialComputeTime: секунды вычислений до capture; прибавляются
  ко второму интервалу для stepComputeTime либо failedComputeTime при ошибке.
  Отрисовка capture исключена из замера; next сбрасывает частичное время.
dtUsed: фактически выполненный интервал; на снимке 0 равен 0, секунды.
elapsedTime: накопленное модельное время снимка, секунды.
step: скалярный номер снимка от 0.
outputRoot: аргумент simulationReport('start',...), по умолчанию results/ проекта.
maxSteps: аргумент start; лимит автоматического режима, по умолчанию 10000.
session: persistent-структура simulationReport; содержит параметры, result,
  recordResults, maxSteps, snapshots (число записанных/показанных снимков),
  dtUsed (следующий выполняемый интервал), timer (идентификатор tic либо [])
  и lastNet (последнее принятое состояние, до снимка 0 — исходные параметры).
  start сбрасывает сессию, finish/fail освобождает. Одновременно ведётся один запуск.
restoredNet: второй выход simulationReport; при fail — копия lastNet для
  восстановления Net в main; иначе входной Net. Новые поля Net не добавляются.
options: третий вход simulationReport; logical для start, MException для fail.

targetAxes: необязательный дескриптор осей drawNetwork для скрытой отрисовки.

7. ВЫЧИСЛИТЕЛЬНОЕ ВРЕМЯ (сверено 21.09.2026)
stepComputeTime: скаляр double, секунды настенного времени для снимка.
  Шаг 0: solvePressureFlow, calcTimeStep.
  Следующие шаги: копирование *_prev и весь расчётный блок в main.
totalComputeTime в step_*.mat: сумма stepComputeTime от шага 0 включительно.
result.totalComputeTime: сумма времени завершённых снимков и failedComputeTime,
  секунды. Счётчик в последнем снимке не включает последующее неудачное вычисление.
result.failedComputeTime: время вычисления до перехваченной ошибки, секунды;
  0 при штатном завершении или ошибке вне активного замера. Учитывается через
  measureComputeTime('fail',...). steps и модельное время при этом не растут.
Таймер запускается после записи параметров/диалога и останавливается перед
записью снимка/отрисовкой. Запись MAT, PDF, графики, ожидание диалога и начальная
инициализация Net не входят в измерение. Время — прошедшее, а не CPU time.
Старые MAT без этих полей поддерживаются PDF: «не измерялось».

8. ПРОВЕРКА СОХРАНЁННЫХ РЕЗУЛЬТАТОВ (18.09.2026; tests/checkResults.m)

Новых полей Net проверка не добавляет. Все вычисления выполняются на копиях.
resultsTarget/target: путь results или отдельной папки запуска.
options/tol: скалярная структура настраиваемых допусков:
  flow=1e-19 м³/с: 1e-8 (Newton tol) * 1e-11 (qScale).
    Баланс узла и неподвижный расход должны удовлетворять abs(value)<flow;
    подвижный расход должен иметь abs(Q)>flow. Знак меньшего расхода не сравнивается.
  pressure=1e-5 Па: 1e-8 * 1e3 (pScale), для диапазона P и порога Pc.
    Это диагностический допуск, не гарантированная ошибка отдельного P.
  saturation=1e-12: допуск сравнения насыщенностей, безразмерный.
  time=1e-12 с и relative=1e-10: abs(a-b)<=time+relative*max(abs(a),abs(b)).
    +Inf совпадает только с +Inf. NaN недопустим.
  Порог завершения мениска 1-1e-12 фиксирован формулой calcState;
    он не меняется при настройке допуска сравнения saturation.
C: локальная структура с векторами полей капилляров в порядке H(:), затем V(:).
  row/col: индексы в исходной матрице; nH: число горизонтальных капилляров.
  first/second: индексы начального/конечного узла в P(:), 0 — внешний конец.
  nodes: число внутренних узлов. closed/seeds/leftH: логические маски границ.
  dP=Dir*DeltaP и Pc=2*sigma*cos(theta)/sqrt(A/pi): Па.
allowed: логический вектор разрешённого пути отвода воды со стороны мениска.
expectedSat/State/Dir/Move: ожидаемые поля для проверки перехода;
  ожидаемое продвижение использует предыдущие Q и dtUsed, а не новый Net.dt.
reports/testSummary: массив структур с результатом для каждой папки:
  directory, report — пути; steps — число проверенных снимков, включая шаг 0;
  errors, warnings — количества сообщений; allCorrect — логический итог.
ERROR/WARNING — уровни отчёта; это не коды State/Move и не поля Net.
Итог all correct разрешён только при отсутствии обоих уровней.

9. МАКЕТ PDF (21.09.2026; reporting/writeSimulationReport.m)
width/height: скалярные размеры макета в условных пикселях; height не меньше
ceil(width*1106/806), чтобы большие сети сохраняли книжную ориентацию.
Размер PDF явно задан в пунктах (1 pt = 1/72 дюйма): 0.75*размер+3.5.
Для текущей сети 3x3 это 806x1106 pt, независимо от размера экрана.
networkLegend: дескриптор узкой легенды справа от рисунка, одна колонка,
  шрифт 7 pt и дополнительные переносы строк.
leftCenter/rightCenter: центры колонок H/V в условных пикселях страницы.
  Таблица давления шириной 280 центрирована по leftCenter;
  блок «сеть + легенда» центрирован по rightCenter.
networkWidth=270, legendWidth=145, legendGap=20: размеры сети, легенды
  и промежутка между ними в условных пикселях страницы; высота сети 270.
networkLeft: левая граница блока, rightCenter-(networkWidth+legendGap+legendWidth)/2.
legendText: подписи легенды с дополнительными переносами; расчётных данных нет.
Пределы X: [-0.3, H.Nx+0.3]; Y: [-1.3, H.Ny+0.3] в условных координатах
рисунка. Физические величины и поля Net не изменяются.
На титульном листе выводятся p_c=2*sigma*cos(theta)/sqrt(A/pi) для H и V,
Па. На странице шага под основными полями выводятся сохранённые матрицы
Move из reportNet (старые MAT: Net), затем Δp-p_c, Па, только для State=1.
Δp вычислен из P того же снимка в направлении Dir. Пересчёта Move в отчёте нет.
«—» означает, что в капилляре нет текущего мениска.
