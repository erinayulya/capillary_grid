# Обновление физики одного мениска — 08.10.2026

Изменения внесены по явному поручению пользователя, синхронизированы с `2023a`.

В `main.m` заданы `Net.k=3.29015`, `Net.coef=6.644123616564944e-4` Па·м^(5/4), `Net.xi=30.079341699546497`, `Net.P_crit_width=4` Па. В `run.m` этих параметров нет; угол ограничен открытым интервалом `(0,pi)`, поскольку на концах вырождается коэффициент плато.

Для движущегося мениска используется приложенный перепад `dp=Dir*DeltaP`, без вычитания старого статического давления:

- `A_class=8*L*(mu1*(1-Sat)+mu2*Sat)/r^2`;
- `A_add=xi*(mu1+mu2)/r`;
- `B=2*k*sigma*sin(theta)/r*(muSm/sigma)^(1/3)`;
- `P_crit=coef*r^(-5/4)`;
- ниже `P_crit-width/2`: `v=(dp/B)^3`, выше `P_crit+width/2`: `v=dp/(A_class+A_add)`;
- внутри полосы квинтический вес смешивает скорости; аналитическая производная включает производную веса;
- `Q=A*v`, `f=q-Q`, `dfdq=1`;
- `Move=2` сохраняет прежнее защемление; `Move=3` при `dp<=0`, `Move=1` при `dp>0`;
- `Regime=1/3` обозначает стороны центра перехода; самостоятельного третьего режима нет.

Вязкости, длина, давления и геометрия по умолчанию сохранены. Табличное значение `A_class=1494.4` не введено как универсальная константа: в сети сопротивление вычисляется по текущим физическим параметрам и насыщенности.

Старая отрицательная поправка к сопротивлению и отключённое полное уравнение удалены. `kdyn/bound` удаляются из новых входных параметров, но поддерживаются при чтении архивных MAT. Новая метка MAT — `flowLaw='smoothMeniscusAppliedPressure'`. Отчёт показывает новые коэффициенты и `P_crit`; таблица `dp-P_crit` означает положение относительно переключения, а не условие остановки.
