СОХРАНЁННЫЕ СЕТИ

Папка содержит именованные геометрии, созданные кнопкой «Сохранить сеть» в run.
Один <название>.mat на сеть. Переменная mesh — скалярная структура:
  formatVersion = 1;
  name — название сети;
  Ah — площади горизонтальных капилляров, м², nRows × (nCols+1);
  Av — площади вертикальных капилляров, м², (nRows+1) × nCols;
  areaUnit = 'm^2'.

Только положительные конечные действительные значения.
Физические параметры, состояния менисков и результаты расчёта не сохраняются.
Выбор файла — в run: «Геометрия сети» → «Выбрать из сохраненных».
При совпадении названия окно спрашивает подтверждение замены.
Случайная сеть после сохранения автоматически выбирается из библиотеки,
чтобы следующий запуск использовал именно эти Ah/Av без новой генерации.

У версий 2025b и 2023a отдельные папки mesh/saved_mesh. MAT-файлы можно копировать
между ними; формат одинаков и использует обычный MAT (-mat).
Папка с данными не добавляется в MATLAB path.
