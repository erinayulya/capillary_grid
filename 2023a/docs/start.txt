ЗАПУСК ПРОЕКТА
Обновлено 27.10.2026: библиотека сетей и импорт площадей.

В MATLAB перейти в корень capillary_grid.

  run                 окно параметров (сохраняется прежнее имя)
  main                интерактивный расчёт с текущей логикой main

В окне run три раскрывающиеся группы: «Физические параметры» (модель и
граничные условия), «Параметры сети» (геометрия) и «Результаты» (сохранение шагов).
При открытии все три группы раскрыты. Нажатие заголовка со стрелкой
раскрывает или сворачивает группу. В физических параметрах давление
на левой границе расположено перед моделью движения мениска и галочкой A_add.

В run доступны две настройки модели:
- «Учитывать A_add в вязком режиме» — галочка, по умолчанию включена.
- «Модель движения мениска» — «Один режим (вязкий)» либо
  «Два режима (плато и вязкий)»; по умолчанию второй вариант.
Для классического вязкого сопротивления выберите один режим и снимите галочку.
Выбор передаётся отдельно как runModelOptions и применяется только в main.
Для прямого запуска изменяйте includeAadd (true/false) и meniscusModel (1/2)
в блоке параметров main; значения по умолчанию true и 2.

В группе «Параметры сети» есть список «Геометрия сети»:
- «Использовать предыдущую» — точные матрицы сети последнего запуска из окна,
  включая прежнее случайное распределение площадей. Все поля новой сети скрыты.
- «Создать новую» — «Матрица площадей», «Случайная» или «Загрузить».
- «Выбрать из сохраненных» — раскрывающийся список сетей из saved_mesh.
В новой сети кнопка «Сохранить сеть» проверяет матрицы, спрашивает название
и записывает <название>.mat в saved_mesh рядом с model/reporting активной версии.
При повторном имени требуется подтверждение замены. После сохранения выбрана
сохранённая запись: даже случайная сеть используется повторно без нового rand.
При «Загрузить» выберите отдельно горизонтальную и вертикальную матрицы;
рядом показаны пути, полный путь доступен во всплывающей подсказке.
Excel .xlsx/.xls: первый лист, только числа, без заголовков и пропусков.
.m: одна числовая матрица, например A = [1e-8 2e-8;3e-8 4e-8];
Комментарии % и переносы ... допустимы; выражения и команды не выполняются.
Все площади в м²; Ah: nRows×(nCols+1), Av: (nRows+1)×nCols.
Для примера согласованной пары: Ah = [1e-8 2e-8]; Av = [3e-8;4e-8];
Каждая матрица в отдельном файле. Все значения должны быть положительными конечными.
У 2025b и 2023a отдельные saved_mesh; MAT-файлы можно копировать между ними.
Если предыдущая сеть ещё не сохранена, сначала задайте и запустите новую.
«Сохранить» запоминает ввод, но не генерирует случайные площади и не заменяет
предыдущую сеть. Фактические H.A/V.A сохраняются при «Сохранить и запустить».
Галочка проницаемости верхней/нижней границы удалена: из run они всегда закрыты.
Физика рассчитана для диаметров 0.1–1 мм включительно. Матрицы main/run
по умолчанию дают диаметры 0.2–0.447 мм; случайный диапазон run — 0.1–1 мм.
При выходе хотя бы одного диаметра за диапазон перед расчётом в командном
окне MATLAB появляется предупреждение:
«Расчет рассчитан для капилляров диаметром от 0.1 до 1 мм».
Расчёт продолжается; введённые площади автоматически не меняются.
«Сохранить» записывает все значения элементов ввода в общий файл run-settings.mat
в корне capillary_grid и оставляет окно открытым. «Сохранить и запустить»
проверяет параметры, получает геометрию и сохраняет ввод с фактическими матрицами
перед запуском main.
Сохранённые значения восстанавливаются после любого числа открытий/закрытий,
clearvars и перезапуска MATLAB. Обычное закрытие не меняет сохранённое;
несохранённые изменения отбрасываются. Пока файла нет, доступны прежние дефолты
либо ввод из кеша предыдущей версии окна. Новая случайная выборка создаётся
при запуске новой случайной сети или «Сохранить сеть» в случайном режиме; предыдущая и сохранённая сети повторяются точно.
Прямой main не читает настройки окна.

Окно вписывается в монитор с указателем мыши. Шрифты сохраняют размер;
при раскрытии нескольких групп содержимое прокручивается. Нижние три кнопки
«Нарисовать», «Сохранить», «Сохранить и запустить» всегда остаются видимыми.

Обе точки запуска сами вызывают setupProject. Для отдельных функций:

  setupProject
  % Затем solvePressureFlow(Net), drawNetwork(Net) и т. д.

При работе из другой папки сначала подключить корень:
  addpath('C:/Users/erina/Documents/MATLAB/Disser/capillary_grid')
  setupProject

setupProject меняет path только текущего сеанса и не сохраняет его глобально.
Не использовать addpath(genpath(...)): подключайте только рабочие папки через
setupProject.

ЗАПУСК И ФОРМИРОВАНИЕ ОТЧЁТА (20.10.2026)

«Сохранить и запустить» автоматически рассчитывает и сохраняет выбранные результаты MAT
без автоматического PDF. «Сохранить» сохраняет только ввод окна, без расчёта.
При необходимости окно формирования PDF можно открыть после расчёта командой
showSimulationReportDialog(simulationResult). Оно содержит выбор «Все» или
«Каждый N» и кнопку «Сформировать».
N — положительное целое число. В PDF всегда входят состояние 0 (t=0)
и последний шаг; остальные — N, 2N, 3N и т.д. без повторения последнего.
Например, 5 шагов: N=2 -> 0,2,4,5; N=3 -> 0,3,5.
Шаг 0 не учитывается в числе выполненных шагов. Выборка окна отчёта меняет только PDF:
PDF использует только имеющиеся MAT. Закрытие окна выбора не создаёт PDF.
Кнопка «Нарисовать» сохраняет предпросмотр геометрии.
При прямом запуске main без флага используется пошаговый режим.
Для записи: runRecordResults = true; main. Флаг действует только на один запуск.
false сохраняет интерактивный режим с рисунками и кнопкой «Продолжить».
true рассчитывает автоматически, без окон графиков и вопросов о продолжении,
сохраняет MAT без автоматического PDF.
Параметры, заданные в run, сохраняются при переходе в main.
Каждый прямой main автоматически очищает предыдущие переменные и начинает
с параметров своего блока инициализации. Старый Net не используется.
При открытии run также очищаются прежние переменные и окна; введённые в окне
параметры передаются в main однократно. Оба запуска закрывают прежние окна
графиков и сбрасывают сессию отчёта. Папки results на диске не удаляются.
После завершения нового расчёта его переменные и новые графики остаются доступны.

Каждый запуск с записью создаёт отдельную папку results/run_<дата>_<уникальный суффикс>/:
- report.pdf: создаётся только по команде формирования; титульный лист,
  начальное состояние (шаг 0), выбранные шаги и последний шаг;
- parameters.mat: Net перед первым вызовом решателя;
- step_000000.mat и последующие: Net (как на странице PDF), solvedNet (после решения),
  reportPhase, flowLaw, step, dtUsed, elapsedTime, stepComputeTime, totalComputeTime;
- summary.mat: result, parameters и последнее принятое Net.

dtUsed - интервал выполненного шага; solvedNet.dt - интервал следующего шага.
С 30.09.2026 на всех шагах Net=solvedNet: P/Q/Move/Regime относятся к одному
принятому решению. reportPhase='afterSolve'. summary.Net — итог решения.
Архивные MAT со снимком до решения сохраняют прежнее содержание при чтении.
Старые MAT с reportNet читаются функцией loadSimulationStep без изменения файла.
На шаге 0 dtUsed=0, elapsedTime=0. Общее время равно сумме dtUsed,
не включает ещё не выполненный следующий шаг и время работы компьютера.
В PDF приведены P и обе ориентации Q, Dir, Sat, State, Move, Regime.
Верхние и левые ячейки индексов таблиц выделены одинаковым цветом.
Большие сети получают увеличенный формат листа, чтобы не обрезать таблицы.
Для просмотра чисел полной точности использовать MAT-файлы.

С 20.10.2026 достижение второй фазой правой границы однократно выводится
в командное окно и запускает проверку стационарности; расчёт продолжается.
Остановка: сатурации/State/Dir/Move стабильны, затем подтверждена стабильность P.
Окно наблюдения: не менее 3 шагов и 1 с модельного времени; Sat-допуск 1e-10,
P-допуск 1e-5 Па + 1e-8*масштаб давления. Скорость изменения Sat дополнительно
исключает ложную остановку из-за малого dt. При Inf dt без подвижных менисков
выполняется подтверждение без продвижения времени (dtUsed=0): проверяются
новые мениски и давление. Установившееся течение может иметь ненулевой расход.
Причина завершения: «Установилось стационарное течение.».
При плохом dt вне этого подтверждения или достижении 10000 шагов
автоматический расчёт завершается с объяснением в summary.mat и окне отчёта;
при формировании причина также выводится на титульном листе.
При перехваченной ошибке сохраняются завершённые MAT, причина ошибки, время
неудачного вычисления, без автоматического PDF; затем MATLAB повторно показывает
исходную ошибку. Net восстанавливается к последнему принятому состоянию.
При принудительном прерывании без catch итоговый PDF может отсутствовать.

Повторная сборка всех шагов: setupProject; writeSimulationReport('путь к папке запуска').
Каждый N: writeSimulationReport('путь к папке запуска',N).
После сборки summary.result содержит pdf, reportStride и reportSteps.
Ошибка формирования PDF не удаляет сохранённые результаты расчёта.
Известные ограничения решателя перечислены в architecture.txt.

Хронометраж (18.09.2026): stepComputeTime — время вычислений данного шага,
totalComputeTime — накопленное время вычислений, включая шаг 0 (секунды).
В summary.mat result.totalComputeTime включает завершённые снимки и
result.failedComputeTime — время неудачного вычисления при перехваченной ошибке. Запись MAT, создание PDF, графики, диалоги
и инициализация main в замер не входят. PDF показывает итог на первом листе,
время шага и накопленное время — на каждом листе состояния.
Для старых MAT без хронометража PDF выводит «не измерялось».

ПРОВЕРКА СОГЛАСОВАННОСТИ СОХРАНЁННЫХ РАСЧЁТОВ (18.09.2026)

Перейти в папку tests рядом с results и выполнить:
  runTests

Будут проверены снимки step_*.mat во всех папках запусков results.
В каждой папке создаётся/перезаписывается tests_relults.txt (имя сохранено
по запросу пользователя). Исходные MAT, PDF и код расчётной модели не меняются.
testSummary в workspace содержит сводку по папкам. Для одной папки:
  report = checkResults(fullfile('..','results','run_20260916_095548_tp06ffb17a_68a5_4738_83fe_865a7d8e5f28'));
Без аргументов checkResults также проверяет results этого проекта.
Функции tests не требуют подключения папок модели: работают независимо,
не вызывают genpath и не запускают новый расчёт.

В отчёте: полный путь MAT, правило, индекс капилляра/узла, значения и причина.
Только при отсутствии ошибок и предупреждений итоговая строка — all correct.
ERROR: нарушение состояния, баланса, перехода, причины завершения либо данные,
без которых часть проверки невозможна. WARNING: дополнительное требование,
которое текущая модель не гарантирует. Предупреждения не скрываются.

Уточнения правил:
1. Первая фаза — State=0; State=1 — мениск; вторая фаза — State=2.
2. P сравнивается с диапазоном граничных давлений: 0, H.P0 и V.P0, если
   вертикальные границы открыты. Границы сортируются, поэтому отрицательный P0
   допустим. Выход P за диапазон отмечается WARNING: при капиллярных перепадах
   или изолированных узлах это не универсальный закон для текущей модели.
3. Допуск баланса и нулевого Q — 1e-19 м³/с по Newton tol*qScale;
   давление сравнивается с допуском 1e-5 Па, Sat — 1e-12.
   Допуск давления не означает доказанную погрешность P. Настройки доступны:
     report = checkResults('путь к папке', struct('flow',1e-18,'pressure',1e-5));
4. sign(Q) сравнивается с Dir только у менисков и вне допуска нулевого расхода.
   Для State=0/2 требуется Dir=0, но Q может быть ненулевым.
5. В новых MAT с flowLaw=smoothMeniscusAppliedPressure Move проверяется по текущему P:
   Move=3 требует dP=Dir*DeltaP<=0 и нулевого расхода; Move=1 требует dP>0.
   P_crit=coef*r^(-5/4) переключает режимы, но не останавливает мениск.
   Старые MAT с twoRegimeCurrentPressure сохраняют проверку dP относительно Pc.
   Несогласованность Move с текущим P вне допуска — ERROR.
   Только архивные MAT без метки сохраняют проверку выбора по прежнему P.
6. В новой схеме неподвижный мениск имеет Regime=0, подвижный — Regime=1/3.
   Валидатор проверяет ветвь и расход по текущему давлению. Архивный режим 2
   поддерживается только при проверке старых MAT без метки нового закона.
7. Move=2 требует Q=0 и сохранения защемления. Причина — потеря пути отвода
   воды/закрытая граница/историческое защемление; dP<=Pc для него не обязательно.
8. Между соседними шагами ожидаемое продвижение восстанавливается по прежним
   Q и dtUsed. Мениск либо остаётся с прежним Dir и ожидаемой Sat, либо
   достигает Sat>=1-1e-12 и превращается в State=2. Новые мениски с Sat=0
   допустимы только на выходящих из достигнутого узла рёбрах по прежнему Q.
   Проверяются лишние и отсутствующие мениски, *_prev и неизменность параметров.
9. Причина завершения сверяется с summary.mat: стационарность после прорыва,
   отсутствие конечного dt, лимит, ручная остановка либо ошибка; для архивов — прорыв.
   Стационарность проверяется повторным наблюдением сохранённых шагов.
   Лимит/ручная остановка не требуют
   неподвижности всех менисков. Для остановки по dt отдельно разбирается каждый
   мениск. Неизвестная причина/отсутствующий summary не выдаёт all correct.

В помеченных MAT независимо проверяются расход и метки Regime текущего закона.
all correct относится к реализованным проверкам, а не доказательству физической модели.
Для контрольных примеров самого валидатора выполнить из tests:
  testCheckResults
Они сохраняются в отдельной автоматически созданной папке tmp/ проекта.

ПЕРИОДИЧНОСТЬ СОХРАНЕНИЯ MAT (20.10.2026)
В группе «Результаты» выберите «Сколько шагов сохранять»:
- «Все» — по умолчанию, сохраняется каждый шаг.
- «Сохранять каждый N шаг» — появляется поле N: положительное целое число.
Нулевой и последний принятый шаг сохраняются всегда, в том числе при ошибке
расчёта. Для 5 шагов: N=2 -> 0,2,4,5; N=3 -> 0,3,5. Если N больше числа шагов,
сохраняются только 0 и последний; если выполнено 0 шагов — только снимок 0.
Промежуточные MAT вне выборки вообще не создаются. Итоговые счётчики и времена
учитывают весь расчёт. Настройка запоминается кнопками сохранения окна.
Периодичность MAT задаётся до запуска и не меняет физический расчёт.
При формировании PDF доступны лишь сохранённые состояния; «Все» в окне PDF
означает все имеющиеся MAT. Дополнительная выборка PDF идёт по номерам шагов.
При выборочной записи checkResults сообщает WARNING HISTORY о невозможности
проверить полную историю переходов и стационарности; каждый доступный снимок
и соседние номера проверяются. Для полной проверки истории выбирайте «Все».
Отсутствие обязательного MAT по result.saveStride/steps остаётся ERROR.

длительность вычислений последнего принятого шага и текущий этап.
После прорыва этап меняется на проверку/подтверждение стационарности.
При завершении или перехваченной ошибке итог выводится сразу, без ожидания 15 с.
Если один шаг занимает дольше 15 с, сообщение появится после его завершения.
Проценты и прогноз окончания не показываются: число шагов заранее неизвестно.
Индикатор работает независимо от выбора MAT «Все»/«Сохранять каждый N шаг».
Новые окна не открываются; прежний текст и предупреждения не стираются.
В пошаговом режиме прямого main сохраняются прежние рисунки и диалоги.

GIF САТУРАЦИИ И ДАВЛЕНИЯ (20.10.2026)
В конце группы «Результаты» включите «Визуализация сатурации и давления».
После «Сохранить и запустить» GIF создаётся после завершения расчёта, рядом
с MAT в results/run_.../saturation_pressure.gif. Галочка сохраняется вместе
с вводом; по умолчанию выключена. Выбранная периодичность MAT определяет кадры.
Для независимой сборки из уже существующих снимков выполните из папки версии:
  setupProject
  gifPath = writeSaturationPressureGif('C:\путь\к\results\run_...');
Без аргументов функция предлагает выбрать папку. Не нужны summary.mat и Net
в workspace. Для другого имени и задержки (секунды/кадр):
  gifPath = writeSaturationPressureGif('C:\папка\расчёта','C:\папка\movie.gif',0.2);
Один сохранённый MAT = один кадр; пропущенные шаги не восстанавливаются.
Холст А4 альбомный: слева нефть чёрная, вода голубая, текущие мениски красные;
справа только цветные точки внутренних узлов Net.P, шкала давления в Па
не меняется между кадрами. В заголовке номер шага и модельное время в секундах.
GIF проигрывается с постоянной задержкой (по умолчанию 0.1 с) и повторяется.
Если расчёт завершился ошибкой, доступные снимки можно обработать вручную.

ВРЕМЯ ОДНОГО КАДРА GIF (20.10.2026)
Когда включена «Визуализация сатурации и давления», под ней появляется
«Время одного кадра, с». Введите длительность показа одного кадра в секундах:
например, 1 — каждый кадр длится 1 секунду. По умолчанию 0.1 с,
допустимый диапазон 0.01..655 с. Настройка сохраняется вместе с остальным вводом.

НЕФТЕНАСЫЩЕННОСТЬ И ПРОГРЕСС (21.10.2026)
Консольный прогресс выводится примерно каждые 15 с между расчётными шагами.
В нём и на GIF показана «Нефтенасыщенность X %»: объём нефти / объём сети.
Площади капилляров учитываются; серые закрытые верхние/нижние отводы не входят
в суммарный объём. Остальные неподвижные и защемлённые капилляры учитываются.
В начале/конце расчёта и при ошибке вывод происходит сразу.
В GIF нет подписей X/Y; диаметр красного мениска равен толщине капилляра.
