Временные CSV/MAT/GIF/PDF/PNG удаляются при успехе и при ошибке.
Переменные в workspace: frontAnalysis, allMenisci, mobileMenisci, frontFits, fourierFits,
harmonicTable, harmonicCosTable, harmonicSinTable.
Таблицы длинного формата: одна строка — один мениск на одном шаге.
Колонки: Step, Time, Orientation, CapillaryRow, CapillaryColumn, X, Y,
Sat, Dir, Move. Идентификатор капилляра — Orientation + индексы;
постоянный идентификатор физического мениска между шагами не назначается.

в координатных таблицах нет строк этого шага.

ГЕОМЕТРИЯ И ВЫБОРКА
X и Y безразмерны, 0..1. Начало — слева внизу, y направлен вверх.
При закрытом верхе/низе X делится на H.Nx, Y на H.Ny-1.
Закрытые вертикальные отводы исключены. При открытом верхе/низе они
включены, исходный y сдвигается на 1 и делится на H.Ny+1.
Однострочная закрытая сеть имеет нулевой размах по Y: все Y=0.
Направление заполнения: H Dir=+1 слева направо, V Dir=+1 сверху вниз.
Включены мениски с Sat=0. Фильтр Move~=2 в точности задан пользователем:
он включает также Move=3 (временно неподвижен) и Move=0 при State=1.
Это отличается от строгого фильтра фактического движения Move==1.

ИНТЕРПОЛЯЦИЯ
Представительный фронт строится как x=f(y). При одинаковом Y вычисляется
среднее X; сами исходные мениски не удаляются из таблиц или GIF.
Для каждой высоты knots хранит Y, Count, X (среднее), XMin и XMax.
При двух и более различных Y соседние средние узлы соединяются прямыми.
Это интерполяция средних узлов, а не подбор кривой через все ветви.
Выбор оптимального семейства функций по ошибке не выполняется.
method='point' означает одну высоту: функция по y не определяется,
на GIF остаются исходные точки. method='none' означает отсутствие точек.
Линия рисуется только в domain=[min(Y),max(Y)], без экстраполяции.
Разрывы и отдельные ветви автоматически не выделяются; возможна линия
через промежуток между разнесёнными по y группами, поэтому точки сохранены.

Получение значения интерполянта кадра k:
  fit = frontFits{k};
  % Только при strcmp(fit.method,'linear') и y в пределах fit.domain:
  x = ppval(fit.pp,y);
pp — структура кусочного полинома с breaks и coefs, пригодная для MAT.
Важно: сам ppval вне domain экстраполирует; программа этого не делает.

РЯД ФУРЬЕ ДЛЯ КАЖДОГО СНИМКА
fourierFits{k} разлагает линейный фронт frontFits{k} по первым 10 гармоникам.
T = yMax-yMin, u=(y-yMin)/T. Для полного интервала [0,1] u=y и T=1.
  x_K(y) = a0 + sum_{n=1..K}(a(n)*cos(2*pi*n*u) + b(n)*sin(2*pi*n*u)).
  a0 = integral_0^1 x(u) du;
  a(n) = 2*integral_0^1 x(u)*cos(2*pi*n*u) du;
  b(n) = 2*integral_0^1 x(u)*sin(2*pi*n*u) du.
Квадратура учитывает все узлы ломаной. Окно и удаление тренда не применяются.
Периодическое продолжение относится к наблюдаемому интервалу; за него кривые
не рисуются. Значения усечённой суммы на обоих концах периода совпадают.
При нескольких X на одном Y разлагается их среднее, как и в frontFits.
MAT хранит a0, a/b (10x1), amplitudes, frequencies=n/T (циклы на нормированную
высоту), angularFrequencies=2*pi*n/T, domain/period, sampleY (501x1),
partialCounts=[1 3 6 10], partialSums (501x4), status, rawPointCount,
formulaLines и formulaText. Коэффициенты хранятся с полной точностью double;
формула в PDF содержит их численные значения с 7 значащими цифрами.
Для пустого кадра status='no-points', для одной высоты 'single-height':
коэффициенты NaN, кривых нет; причина сохранена в formulaText.
Снимки без выбранных менисков не получают отдельной страницы PDF.
Гармоники сохраняются и при выключенных GIF/PDF. Отдельный toolbox не нужен.
  series = frontAnalysis.fourierFits{k};
  disp(series.formulaText);
  plot(series.sampleY,series.partialSums(:,4)); % первые 10 + среднее

GIF имеет выбранную постоянную задержку на кадр; это скорость просмотра,
а не масштаб физического времени. Заголовок показывает реальное Time.
Без диалога, другой расчёт и независимый выбор форматов:
  options = struct('createGif',true,'createPdf',false);
  frontAnalysis = analyzeMeniscusFront(sourceDirectory,[],0.2,options);
Пустой outputDirectory выбирает sourceDirectory/analysis. Явно заданная
выходная папка должна существовать. По умолчанию оба формата включены.
Функции доступны после addpath папки analysis/front_analysis; run_analysis сам временно подключает эту папку.

Совместимость: базовый MATLAB, синтаксис для R2023a и новее.
Используются table, groupsummary, mkpp/ppval, exportgraphics, rgb2ind и imwrite.
PDF экспортируется постранично через Append, без новых параметров R2025a.
Исходные Net, MAT расчёта и расчётные функции не изменяются.

ТАБЛИЦЫ КОЭФФИЦИЕНТОВ И КОПИРОВАНИЕ (03.11.2026)
frontAnalysis.harmonicCosTable и harmonicSinTable — timetable: строки задаются
elapsedTime в секундах (duration), 10 численных столбцов a1..a10 и b1..b10.
Первый столбец данных соответствует первой гармонике. Время — метка строки.
harmonicTable объединяет коэффициенты в порядке a1,b1,a2,b2,...,a10,b10.
Значения — коэффициенты cos/sin, не амплитуды sqrt(a_n^2+b_n^2).
Из таблиц исключаются t=0 и строки с любым недоступным коэффициентом (NaN/Inf).
Повторяющиеся подходящие времена сохраняются отдельными строками. Double в MAT не округляется.
harmonic_coefficients.csv и harmonic_coefficients.tsv сохраняются всегда,
даже без GIF/PDF. Первый столбец Time_s — численное время, далее пары a_n/b_n.
TSV содержит табуляцию: его можно открывать в Excel или копировать столбцами.
Последняя страница PDF содержит два текстовых блока a1..a10 и b1..b10,
со значениями по времени (7 значащих цифр). Текст можно выделять и копировать;
для переноса чисел без округления предназначены CSV/TSV и MAT.
Если строк больше 22, итоговая таблица продолжается на следующих последних листах.
Если подходящих строк нет, итоговый лист содержит заголовки и сообщение об отсутствии данных.
GIF сохраняет все кадры; пропуск пустых снимков относится только к страницам PDF.

НЕПРЕРЫВНЫЙ СПЕКТР (10.11.2026, обе версии).
continuousMeniscusSpectrum(frontFits,times,k) интегрирует кусочно-линейный
профиль x(y)-meanX на фиксированном интервале y=[0,1]. meanX — интеграл
профиля по y. По умолчанию k=linspace(0,20*pi,1001), рад на нормированную
высоту. Это значения непрерывного преобразования, не интерполяция БПФ.
Интегралы по сегментам аналитические; малые аргументы обработаны рядами.
A=2*abs(F), доля ширины сети, не мощность и не спектральная плотность.
Вне интервала отклонение равно нулю. Профили без полного покрытия [0,1],
пустые и одноточечные профили не экстраполируются: NaN, valid=false.
В run_analysis переменная continuousSpectrum содержит k, time, transform,
amplitude (Nk x Nframes), meanX, valid, status, domain и описание нормировки.
Обычный анализ сохраняет её в front_analysis.mat как поле frontAnalysis.
Краткий отчёт сохраняет отдельный analysis/continuous_spectrum.mat.
Таблицы гармоник из краткого HTML удалены. Вместо них один книжный лист A4:
карта 170 мм по ширине (как последняя сатурация), поля страницы 20 мм,
заголовок, формула и пояснения. Время по X, k по Y, цвет — A, общая линейная
шкала. Серый — недоступные данные; нулевой спектр имеет цвет нуля.
Границы полос посередине между временами, без интерполяции по времени;
при повторении времени показан последний снимок (MAT сохраняет все).
k<2*pi соответствует длинам волн больше высоты сети; пики не доказывают
периодичность. Для единственного снимка ширина полосы условная (1 с).
Обычные PDF и таблицы дискретных гармоник сохранены.
Использован синтаксис MATLAB R2023a; исполнение проверять отдельно от R2025b.
