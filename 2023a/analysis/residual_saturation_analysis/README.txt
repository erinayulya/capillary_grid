АНАЛИЗ КЛАСТЕРОВ ВЫТЕСНЯЕМОЙ ФАЗЫ
Дата сверки: 03.11.2026.

Основной запуск: run_analysis.m рядом с run.m. В его диалоге выберите папку
расчёта и включите «Анализ кластеров с остаточной насыщенностью». При включённом
«Сформировать PDF» составы кластеров и итоговая таблица добавляются в конец
общего PDF анализа mobile_front.pdf. Без PDF сохраняются только данные и таблицы.
Все результаты фронта и кластеров находятся прямо в results/run_.../analysis;
вложенные front_analysis/residual_saturation_analysis здесь не создаются.
Отмена ничего не записывает. Нет изменений параметров симуляции и Net.

Дополнительный скрипт analysis/residual_saturation_analysis/run_residual_analysis.m
также сохраняет результаты прямо в analysis. С галочкой формирует тот же общий
PDF фронта и кластеров, без галочки - только CSV/MAT кластеров. summary.mat
для постобработки не нужен: достаточно сохранённых step_*.mat.

Последний снимок выбирается по МАКСИМАЛЬНОМУ ЧИСЛЕННОМУ номеру step_*.mat,
а не по времени изменения или строковой сортировке имени. Предпочтение solvedNet,
для старых файлов без solvedNet используется Net. Ошибка последнего снимка
не подменяется результатом более раннего. summary.mat для одних таблиц не нужен.

СВЯЗНОСТЬ
Sat - доля вытесняющей фазы. При закачке нефти анализируется вода, при закачке
воды - нефть. В старых файлах без displacingPhase предполагается закачка нефти.
Сначала находятся все каналы с положительным остатком вытесняемой фазы (Sat<1).
Затем ЦЕЛИКОМ исключаются компоненты, имеющие связь с правой границей именно
по вытесняемой фазе. Остальные каналы исключённого кластера тоже не считаются.
Если справа у граничного канала вытесняющая фаза, одной геометрической связи
с правой границей недостаточно для исключения. При Sat=0 оба конца доступны.
Открытый нижний выход сам по себе не является основанием исключать кластер.
State=0/Sat=0: вытесняемая фаза доходит до обоих концов канала.
State=1, 0<Sat<1: при Dir=+1 вытесняемая фаза находится у второго конца
(правого у H, нижнего у V), при Dir=-1 - у первого (левого/верхнего).
State=1/Sat=0: оба конца доступны, объём вытесняющей фазы равен нулю.
State=2/Sat=1, а также State=1/Sat=1: остатка нет, канал не учитывается.
Некорректные состояния, направления, насыщенности и геометрия вызывают ошибку.

Два канала объединяются только через общий ВНУТРЕННИЙ узел, к которому
вытесняемая фаза подходит с обеих сторон. Геометрическое соседство само по
себе не является связью. Поэтому вода-нефть-узел-вода-нефть даёт два кластера,
если между ними нет другого пути по вытесняемой фазе через сеть.
Сегменты представлены вершинами двудольного графа «канал - доступный узел».
Связные компоненты находят через graph/conncomp. Один канал считается один раз.
Промежутки внутри канала с несколькими менисками не моделируются исходным Net.

При закрытом верхе/низе крайние строки V исключены из анализа и порового объёма.
Внешние резервуары не объединяют разные граничные каналы в один кластер.
ConnectedToOutlet: компонент имеет путь по вытесняемой фазе к правой границе
либо к открытой нижней границе. TouchesBoundary отмечает также входные границы.
Фильтра по Move или Q нет. Таблицы содержат только кластеры БЕЗ связи
с правой границей по вытесняемой фазе. Пометка
«изолирован» здесь означает отсутствие связи с выходом, а не доказательство
полной неподвижности при любых давлениях. Остановленный вручную расчёт тоже
можно анализировать; его остатки нельзя автоматически считать предельными.

ТАБЛИЦЫ И ЕДИНИЦЫ
Результаты: results/run_.../analysis/.
  cluster_sizes.csv: ChannelCount (размер), ClusterCount (сколько кластеров),
    HorizontalChannels/VerticalChannels (СУММЫ H/V всех кластеров строки),
    IsolatedClusterCount (сколько из этих кластеров не связано с выходом).
    Строки идут от 1 до максимального размера; отсутствующие размеры имеют 0.
  clusters.csv: ClusterID, ChannelCount, HorizontalCount, VerticalCount,
    DisplacedVolume, ConnectedToOutlet, TouchesBoundary; одна строка на кластер.
  cluster_composition.csv: ChannelCount, HorizontalCount, VerticalCount,
    ClusterCount; частоты сочетаний размера и внутреннего состава H/V.
  cluster_channels.csv: ориентация H/V, индексы строки/столбца в Net, Sat, Dir,
    DisplacedVolume, признаки границ и ClusterID каждого канала.
  residual_saturation.mat: структура residualAnalysis со всеми таблицами,
    исходной папкой/снимком, шагом/временем, объёмами и насыщенностями.
Номера ClusterID локальны для одного снимка; постоянные ID во времени не строятся.
Индексы каналов соответствуют MATLAB, начиная с 1.
Объём сегмента: A*L*(1-Sat), м3. Поровый объём: sum(A*L) геометрически
включённых каналов сети; фильтрация кластеров не уменьшает знаменатель.
displacedVolume содержит только остатки после исключения правограничных кластеров.
totalDisplacedVolume - весь объём вытесняемой фазы до фильтра.
excludedRightConnectedVolume/ChannelCount/ClusterCount - исключённые объём,
число каналов и число кластеров (общий префикс excludedRightConnected).
Эти три величины сохраняются в MAT; исключённые компоненты в CSV не попадают.
ConnectedToRightBoundary в channels относится к контакту конца канала с правым
резервуаром по вытесняемой фазе; после фильтра во всех оставшихся строках false.
displacedSaturation = displacedVolume/poreVolume, безразмерная доля.
isolatedVolume/isolatedSaturation относятся только к компонентам без связи с выходом.
Размер кластера - число каналов, а не объём. Узлы собственного объёма не имеют.

PDF: после обычных страниц расчёта выводятся составы отдельных кластеров
(ID, размер, H, V, объём, связь с выходом), затем распределение размеров.
Итоговая сводка всегда последняя. Большие таблицы продолжаются на следующих
последних листах, строки не обрезаются. Текст PDF выделяется и копируется.
При отсутствии подходящих кластеров таблицы пусты, PDF содержит явное сообщение.
PDF также показывает, сколько кластеров и каналов исключено по правой границе.
frontAnalysis.residualAnalysis хранит таблицы, исходный шаг и путь снимка;
frontAnalysis.pdfPageCount учитывает все страницы общего PDF анализа.

Явно заданная outputDirectory вторым аргументом analyzeResidualSaturation должна
существовать. Выходные файлы сначала готовятся временно, затем заменяют прежние.
Net, исходные снимки, main.m, model/ и solver/ не изменяются.

СОВМЕСТИМОСТЬ
Код написан для базового MATLAB R2023a и новее. graph/conncomp доступны с R2015b,
экспорт PDF использует Append (R2021b), без параметров экспорта R2025a.
AutoResizeChildren устанавливается только при isprop.
Проверки запуска выполняются в установленном MATLAB R2025b; это не проверка
выполнения в R2023a (эта версия не установлена).
Документация API: https://www.mathworks.com/help/matlab/ref/graph.conncomp.html
https://www.mathworks.com/help/matlab/ref/exportgraphics.html

Рисунок сатураций на листе кластеров (03.11.2026): writeResidualClusterPdf
читает solvedNet последнего снимка (старые файлы: Net) и использует общий
с GIF из run renderer drawSaturationPressureFrame. На листе распределения
размеров отображается только сатурация, без поля давления, с легендой фаз
и менисками. На лист помещается 8 строк таблицы; длинные таблицы продолжаются
на следующих листах с тем же рисунком. Исходные снимки и Net не изменяются.
